项目

用于分子建模与构效分析的桌面软件。

两个给化学用的桌面软件，跑在 Windows 和 Linux 上，本地运行。

MolStudio

分子建模与对接工作站。

  • 3D 构建、受体准备、AutoDock Vina 对接
  • 2D 相互作用图，标注距离、π–π 堆积与盐桥
  • 绘图、可重新打开的会话，SDF / CSV / PNG / SVG 导出

状态： v1.0。免费版没有期限；一次性授权解锁完整流程。

产品页 · 下载

MolInsight

构效分析工作台，用来回答「为什么这个取代基更好」。

  • 47 种图表，含小倍数、分面与 3D
  • MMP，带对数、离散度与显著性
  • R 基团矩阵、骨架与侧链分析
  • 聚类、相似性网络与自组织映射
  • QSAR：ridge / PLS / 核岭回归 / KNN / GBM，带适用域

状态： v1.0。免费版每次会话 100 个化合物；一次性授权取消限制。
