关于

AIDDHub 背后的开发者：两个给药物化学用的桌面软件、这个博客，以及做这两件事的理由。

我是 AIDDHub 背后的开发者。一个人，两个桌面软件，一个博客。

我在做什么

MolStudio，一个建模与对接工作站；MolInsight，一个构效分析工作台。都是 Windows / Linux 原生 程序，离线运行，只卖一次，不需要账号就能用。

代码、文档、安装包、支持邮件和这里的文章都是我自己写。这不是谦虚话——它是功能范围一直很小的原因， 也是有些看起来很明显的功能到现在还没做的原因。

为什么写博客

产品页写不了细微的东西。它没法解释为什么 −8 的对接打分什么也证明不了，也没法解释三对化合物的 MMP p 值只是装饰，因为写这些不是销售话术。

所以文字放在这里：把失败步骤也写进去的完整流程、第一次做错的技术决策的复盘，以及偶尔关于化学软件 的随笔。教程是实用的那一半，随笔是本来也会写的那一半。

这里发表的东西都会在当前版本上核对；功能改了，文章跟着改；我错了的地方会写清楚，并且把更正留在原文里。

我的做法

  • 本地优先。 结构、活性表、模型留在你自己的机器上，分析过程不上传——也没有服务器可上传。
  • 一次性授权。 不做订阅。免费版能做完真实的工作，没有期限，导出不加水印。
  • Windows 与 Linux。 原生安装包，不需要 Java 运行时、不需要 conda，按用户安装不需要管理员权限。
  • 中英双语。 界面、文档和这个站都是两种语言。

这不是什么

不是一个有销售团队、合作伙伴计划和企业版的公司。没有管理后台，没有 SSO——那些本身就是独立的产品， 用一个勾选框糊弄过去只会浪费买家的一个下午。

需要十个席位，就买十份授权。就这么简单。

联系

缺陷报告、勘误、功能建议、授权问题都发 support@aiddhub.com。我全都看，中英文都可以，通常几天内回复。

这个站上如果有写错的地方，告诉我确实有用——你花两分钟，下一个读者省一个下午。
