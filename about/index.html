About AIDDHub

An independent software studio building desktop tools for medicinal chemistry: MolStudio for modelling and docking, MolInsight for SAR analysis.

AIDDHub is a small, independent software studio. We build desktop tools for medicinal chemistry and structural biology — the kind of software you install once, run locally, and use while you are thinking about a series rather than about your environment.

Why these notes exist

Most chemistry software documentation tells you what each button does. Very little of it tells you what to do on a Tuesday afternoon when a reviewer asks why you believe a substituent is better.

So this site is not documentation. It is the material we wished existed when we started: complete walkthroughs that start from a real task, show the clicks, report the numbers honestly, and end with a figure or a sentence you can put into a report.

Everything published here is tested on the current release before it goes out. When a feature changes, the article changes with it.

What we build

MolStudio — molecular modelling workstation

A 3D builder and docking environment for the desktop: import a PDB, prepare the receptor, dock a ligand library with AutoDock Vina, inspect the interactions in 2D and 3D, plot the results and save the whole session.

One-time licence, $149. A free tier covers the full workflow with no time limit.

MolInsight — SAR analysis workbench

The analysis side: 47 chart types, matched molecular pairs with significance estimates, R-group matrices, scaffold and side-chain analysis, clustering and self-organising maps, QSAR with an applicability domain.

One-time licence, $99. The free tier handles 100 compounds per session.

Both are available together as a bundle for $199, and both are priced in Chinese yuan for the domestic market.

How we work

  • Local first. Structures, assay tables and models stay on your machine. Nothing is uploaded to a server to be analysed.
  • One-time licences. No subscription, no per-seat renewal, no feature that stops working when a billing cycle ends.
  • Windows and Linux. Native installers; no Java runtime, no conda environment, no admin rights required for a per-user install.
  • English and Chinese. The interface and the documentation exist in both.

Getting in touch

Bug reports, feature requests and questions about a licence all go to the same place: support@aiddhub.com. We answer in English or Chinese.

The products live at www.aiddhub.com.
